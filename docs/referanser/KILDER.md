# Referanser, designrunde 2 (hentet 2026-10-20)

Skjermbilder i 1280 px bredde (beskåret til maks 1800 px høyde) av offentlige nettsider, brukt som visuelle referanser før designarbeidet. Rettighetene tilhører eierne. Bildene brukes ikke i designet, bare til sammenligning.

| Fil | Kilde | Hva vi så etter |
|---|---|---|
| nattsiden-1-stripepress | https://press.stripe.com | Varm mørk flate, ett objekt |
| nattsiden-2-palantir | https://www.palantir.com | Alvor og ett varmt lys i mørke (lån alvoret, ikke mørket) |
| nattsiden-3-anduril | https://www.anduril.com | Fullbredde natt, kondensert versal |
| nattsiden-4-varde | https://commons.wikimedia.org (søk: varde Norway) | Hvordan varder faktisk ser ut: tørrmurte tårn av heller |
| nattsiden-5-dagens-vardark | https://vardark.no | Dagens side, det som skal bort |
| steinen-1-nrkbeta | https://nrkbeta.no | Norsk tone, store titler |
| steinen-2-basalt | https://commons.wikimedia.org (søk: basalt columns Norway) | Stein som materiale |
| steinen-3-simonwillison | https://simonwillison.net | Essayformat som har tålt tid |
| steinen-4-operaen | https://commons.wikimedia.org (søk: Oslo Opera House roof) | Hvit stein, vinkler, lys |
| steinen-5-snohetta-opera | https://snohetta.com/projects/norwegian-national-opera-and-ballet | Stor grotesk over fotografi |
| observatoriet-1-singularity | https://singularity.vardark.no/tracker | Kristians eget observatorium |
| observatoriet-2-eso | https://www.eso.org/public/ | Observatorium som institusjon |
| observatoriet-3-epoch | https://epoch.ai | Store tall og diagrammer |
| observatoriet-4-ourworldindata | https://ourworldindata.org/artificial-intelligence | Data som fortelling |
| observatoriet-5-nasa-webb | https://science.nasa.gov/mission/webb/ | Tittel mot stjernefelt |

stratechery.com ble forsøkt, men krever menneskesjekk og ga ikke noe skjermbilde.

## Bildemateriale på siden
Alt bildemateriale (nattlandskap med varde, basalt, stjernefelt) er generert prosedyrisk av `docs/designrunde-2/materiale.py`. Ingen eksterne bilder, ingen lisensbindinger.
